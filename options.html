OTP 자동입력 설정

국민대 포털 OTP 화면(portal.kookmin.ac.kr/por/otp)에서, 메일로 온 [ON국민포털] 인증번호 … 메일의 제목에서 번호를 읽어 입력칸에 채워줍니다. 확인 버튼은 직접 눌러야 합니다.
동작 방식 · 보안
  • OTP 화면이 열렸을 때만, 최대 60초 동안 3초마다 메일을 확인합니다. 평소에는 메일을 읽지 않습니다.
  • 지정한 라벨/메일함의 안 읽은 메일 중 최신 2개의 제목만 보고, OTP 화면을 연 뒤에 도착한 메일만 사용합니다. 이전 로그인 시도 때 받은 번호는 무시합니다.
  • 비밀번호는 필요 없습니다. 이 브라우저에 로그인된 Gmail/Naver 세션을 그대로 사용합니다.
  • 설정과 메일 내용은 외부 서버로 전송되지 않습니다. 설정은 이 브라우저에만 저장됩니다.
  • 같은 PC에서 OTP까지 자동 입력되므로, 공용 PC에서는 사용하지 마세요.
Gmail Gmail 주소창 mail.google.com/mail/u/0/의 숫자. 브라우저에 로그인한 첫 번째 Google 계정이면 0 OTP 메일에 붙는 라벨 이름 (Gmail 왼쪽 목록에 보이는 이름 그대로). 띄어쓰기와 하위 라벨(상위/하위)은 권장하지 않습니다. 단어를 구분하려면 _를 사용하세요 (예: school_otp)
Gmail 설정 방법
  1. 학교에서 받은 OTP 메일을 열어 보낸사람 주소를 확인합니다.
  2. Gmail 검색창 오른쪽의 검색 옵션 아이콘을 누릅니다.
  3. 보낸사람에 1번 주소를 입력하고 필터 만들기를 누릅니다.
  4. 라벨 적용을 체크 → 새 라벨 → 띄어쓰기 없이 라벨을 만들고(예: otp, school_otp) 필터 만들기를 누릅니다.
  5. 이 브라우저에서 Gmail에 로그인된 상태를 유지합니다.
  6. 위의 Gmail에서 OTP 읽기를 체크하고, 4번에서 만든 라벨 이름을 입력해 저장합니다.
Naver 메일 비워두면 Naver는 사용하지 않습니다. OTP 메일이 들어가는 메일함 이름 (대소문자·띄어쓰기까지 정확히)
Naver 설정 방법
  1. 학교에서 받은 OTP 메일을 열어 보낸사람 주소를 확인합니다.
  2. Naver 메일 왼쪽 메일함 목록에서 메일함 추가로 메일함을 만듭니다(예: otp).
  3. Naver 메일 환경설정 → 메일 분류(필터)에서 규칙을 추가합니다: 보낸사람 = 1번 주소 → 2번 메일함으로 이동.
  4. 이 브라우저에서 Naver에 로그인된 상태를 유지합니다.
  5. 위에 Naver 아이디(이메일의 @ 앞부분)와 2번 메일함 이름을 입력하고 저장합니다.
잘 안 될 때
  • OTP 메일을 먼저 열어보면 읽음 처리되어 대상에서 빠집니다. 안 읽은 상태로 두세요.
  • 메일이 3분 넘게 늦게 오면 사용하지 않습니다. 인증번호를 재요청하세요.
  • 설정을 바꾼 뒤에는 OTP 화면을 새로고침하세요.
  • 원인 확인: OTP 화면에서 F12 → Console, 그리고 chrome://extensions → 이 확장의 "서비스 워커" → Console 에서 [OTP autofill] 로그를 확인합니다. (로그에 번호·메일 내용은 남지 않습니다)
